# Automated Recon Framework

## Overview

A Linux-based automated reconnaissance and vulnerability assessment framework designed to automate host discovery, service enumeration, vulnerability detection and reporting.

The framework integrates multiple open-source security tools into a single workflow, reducing manual effort during security assessments.

---

## Project Status

This project is currently under active development.

Current functionality includes:

- Host Discovery
- Port Scanning
- Service Enumeration
- Vulnerability Detection
- Web Application Analysis
- SMB Enumeration
- SNMP Enumeration
- DNS Reconnaissance
- Automated HTML Reporting

Planned Improvements:

- Enhanced error handling
- Improved reporting
- Additional vulnerability checks
- Configuration management improvements

## Why I Built This

I developed this project to improve my understanding of network reconnaissance, vulnerability assessment, automation and security reporting.

The goal was to consolidate multiple security tools into a single workflow while producing actionable and organised assessment results.
